# K1 头部与腰部使用说明

基于现有 K1 头腰独立控制节点，使用 `xarm_can` 目录内交付的预编译头腰绑定。以下路径均相对于 SDK 根目录。

## 1. 环境与 SDK

支持 Ubuntu 22.04、ROS 2 Humble、CPython 3.10，提供 Linux x86_64 与 aarch64 预编译扩展，无需在客户机器编译 C++ 驱动。
机械臂使用 `xarm_can`，头腰使用 `k1_head_waist_can`，两者可以同时导入。

```bash
PYTHON_BIN=/usr/bin/python3 bash scripts/install_can_python.sh
source /opt/ros/humble/setup.bash
```

SDK 随包路径为 `publish/xarm_can/head_waist/python/prebuilt/`，许可证位于 `publish/xarm_can/head_waist/licenses/`。

## 2. 模块与参数

| 轴 | 默认 CAN | 电机类型 | 发送/反馈 ID | 目标角度范围 | kp/kd |
|---|---|---|---|---|---|
| 头 Pitch | can0 | DM4310 | 0x0B/0x1B | 0°～24° | 40/1.2 |
| 头 Yaw | can0 | DM4310 | 0x0C/0x1C | −45°～45° | 40/1.2 |
| 腰 Pitch | can1 | DM10422P | 0x0A/0x1A | −30°～30° | 500/5 |
| 腰 Yaw | can1 | DM8009 | 0x09/0x19 | −90°～90° | 400/5 |

实际 CAN 接线须与目标设备核对。程序使用 500 Hz 定时器，目标变化速率上限为 20°/s；这些是软件参数，不代表已经验证的机械行程。

## 3. 启动

启动节点通过初始反馈检查后会使能对应两台电机。启动前确认 CAN 已正确配置、机构有支撑、急停可用；避免其他程序同时向相同电机 ID 发送指令。

头部：

```bash
ROS_SETUP=/opt/ros/humble/setup.bash PYTHON_BIN=/usr/bin/python3 \
  bash publish/modules/src/xarm_head/V1.0.0/head_system/start_head_control.sh
```

腰部：

```bash
ROS_SETUP=/opt/ros/humble/setup.bash PYTHON_BIN=/usr/bin/python3 \
  bash publish/modules/src/xarm_waist/V1.0.0/waist_system/start_waist_control.sh
```

终端输入格式为 `pitch_deg yaw_deg`，`state` 查看反馈。按实际机构确认方向后逐轴设置目标。超范围及非有限目标会被拒绝。节点从当前反馈接管，不主动回零；Ctrl+C 正常退出后会失能对应两轴，应保持机构支撑。

## 4. ROS 2 接口

| 模块 | 目标话题 | 状态话题 | 消息类型和顺序 |
|---|---|---|---|
| 头部 | /head/cmd | /head/state | std_msgs/msg/Float64MultiArray，[pitch_deg, yaw_deg] |
| 腰部 | /waist/cmd | /waist/state | std_msgs/msg/Float64MultiArray，[pitch_deg, yaw_deg] |

头腰节点是独立接口，未接入机械臂策略输出或双臂联合规划。确认设备状态后才发送目标；节点间的电机组锁不代替对其他 CAN 控制程序的管理。
